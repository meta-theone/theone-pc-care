# 안전 정책

## 자동으로 가능한 조치

- OneDrive: 총 핸들이 250,000개 이상일 때 공식 종료 옵션을 우선 사용해 다시 시작합니다.
- Windows 탐색기: 기본 탐색기 프로세스의 핸들이 20,000개 이상이거나 스레드가 300개 이상일 때만 다시 시작합니다. 작업표시줄은 자동 복구되지만 열려 있던 폴더 창은 닫힐 수 있습니다.
- Robocopy·Python·노트북 보조 유틸리티: 종료하지 않고 프로세스 우선순위만 낮춥니다.
- RICOH 자동관리·Windows 검색색인: 조건이 맞을 때 현재 세션에서만 일시정지하며 서비스 시작 유형은 변경하지 않습니다.

## 별도 확인이 필요한 조치

중요 업무로 식별된 장기 실행 작업은 정상화 버튼만으로 종료하지 않습니다. 별도 확인창에서 사용자가 동의한 경우에만 예약 작업을 일시중지합니다.

## 하지 않는 조치

- 파일·폴더·휴지통·임시파일 삭제
- 레지스트리 청소
- 브라우저·Office·보안 프로그램 강제 종료
- Google Drive 종료
- CHKDSK 중단
- 서비스 시작 유형 영구 변경
- 원격 전송·원격제어·텔레메트리

## 복구

OneDrive와 Windows 탐색기는 조치 직후 다시 시작합니다. 일시정지한 서비스는 Windows가 자동으로 다시 시작할 수 있으며, 시작 유형은 변경하지 않습니다.
