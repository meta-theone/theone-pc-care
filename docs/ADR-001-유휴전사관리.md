# ADR-001: PC 유휴 상태 기반 전사 작업 관리

**상태:** 채택
**날짜:** 2026-08-25
**결정자:** 더원사업단

## 배경

CPU 기반 음성 전사는 장시간 자원을 사용한다. 사용자가 PC를 조작하는 동안 전사를 계속하면 업무 프로그램의 반응이 느려지지만, 작업을 강제로 끝내면 처리 중이던 결과가 불완전하게 남을 수 있다.

## 결정

키보드·마우스 입력이 10분 동안 없을 때만 전사를 실행한다. 입력이 다시 감지되면 현재의 짧은 전사 구간을 안전하게 마친 뒤 대기한다. 전사 프로세스는 유휴 우선순위로 유지하며 결과 파일은 임시 파일에 완성한 다음 원자적으로 교체한다.

## 검토한 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| 작업 스케줄러의 유휴 옵션만 사용 | 설정이 단순함 | 다중 워커가 부모와 분리되면 중지되지 않을 수 있음 |
| 입력 감지 즉시 프로세스 강제 종료 | CPU가 즉시 내려감 | 처리 중 결과가 깨질 위험이 있음 |
| 전사 프로그램 내부 유휴 게이트 | 결과를 보존하면서 자동 대기·재개 | 전사 코드에 제어 로직이 필요함 |

## 결과

- PC 사용 중 전사는 CPU를 거의 사용하지 않는다.
- 10분 무입력 후 자동으로 이어서 실행한다.
- 완료된 전사본과 원본 음성은 변경하거나 삭제하지 않는다.
- 작업 스케줄러는 시작과 장애 복구를 담당하고, 실제 유휴 판단은 전사 프로그램이 담당한다.
